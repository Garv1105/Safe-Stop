# SafeStop prototype data

Pilot area: 3 km radius around DSCE main gate (12.908 N, 77.566 E), Kumaraswamy Layout, Bengaluru.
Downloaded / generated: **2026-11-06**. Rebuild with the scripts in `scripts/` (see project README).

| File | Contents | Source | Real or synthetic |
|---|---|---|---|
| `lamps.geojson` | Street lamp points (273) | OpenStreetMap `highway=street_lamp` via Overpass API | Real |
| `places.geojson` | Shops, restaurants, cafes, fast food, pharmacies, ATMs, fuel, clinics (1,978) with an estimated closing hour | OpenStreetMap via Overpass. `close` comes from `opening_hours` when tagged (`hoursSource: "osm"`), otherwise a default per category (`hoursSource: "default"`) | Real locations; default hours are assumptions |
| `transit.geojson` | Bus stops and metro stations | OpenStreetMap via Overpass | Real |
| `help.geojson` | Police stations + outposts, hospitals | Police: OpenCity "Bengaluru Urban Police Station Locations" and "Police Outpost Locations" KML (data.opencity.in). Hospitals: OpenStreetMap `amenity=hospital` | Real |
| `cells.json` | 263 H3 res-9 cells: score per time band, parts L/A/T/H, reasons, report counts | Computed by `scripts/build_scores.py` from the files above; report effect added by `make_synthetic_reports.py` | Derived from real data; `reportCounts` and `dR` are **synthetic** |
| `reports.json` | 420 community reports (`"synthetic": true`) | Generated by `scripts/make_synthetic_reports.py`, seed 42, loosely correlated with lighting and activity | **Synthetic: demo only, not real reports** |
| `streets_preview.json` | OSM streets around the DSCE → Konanakunte routes, for the landing page drawing | Cut from the Overpass road data by `scripts/make_street_preview.py` | Real |
| `routes.json` | 3 demo trips from DSCE, 2–3 walking options each | Shortest: OSRM foot profile at routing.openstreetmap.de (FOSSGIS). Safest/balanced: safety-weighted shortest path on the OSM road network (`scripts/fetch_routes.py`) | Real road geometry; route scores use the cell scores above |

Map tiles: OpenFreeMap. Map data © OpenStreetMap contributors, ODbL.

Known limits: few street lamps are mapped in OSM here and almost no roads carry `lit=*`, so the lighting part also uses the share of main roads as a hint. A missing tag is treated as unknown, not dark.
